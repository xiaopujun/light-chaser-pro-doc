# 升级指南

## 升级到 2026.2.0

如果你正在使用下面这些场景，建议升级到 `2026.2.0`：

- 需要运行时同源部署
- 项目里使用了嵌套引用项目
- 项目里使用了公共 API 或数据库数据源，并希望导出后还能继续使用
- 需要对导出项目包做加密保护
- 需要更稳定的 macOS 资源访问和预览体验

### 这次升级后的变化

- 项目可以更方便地打包成 `zip` 文件并再次导入
- 导入加密包时需要填写导入口令
- 发布页面和运行时访问方式更统一
- macOS 下的资源路径和 3D 模型加载更稳定

## 升级建议

- 升级后先打开一个常用项目，确认图片、视频、字体和 3D 模型都能正常显示
- 如果你启用了导出加密，请保管好导出口令
- 如果你使用了公共 API 或数据库数据源，建议再做一次导出和导入验证
