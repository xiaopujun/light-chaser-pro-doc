# 常见问题

## 导入项目后资源显示不正常

- 检查图片、视频、字体和 3D 模型的资源链接是否仍然可访问
- 如果项目包启用了加密，导入时要输入正确的导入口令
- 如果是旧项目，建议先打开主设计器完整预览一次

## 发布页面打不开怎么办

- 先确认你是从项目的“发布管理”或发布链接打开
- 桌面端会在独立窗口里打开，网页端会在新标签页里打开
- 如果页面提示未授权，先检查当前账号权限和项目发布状态

## 桌面端为什么没有更新按钮

- 自动更新只在桌面端提供
- 网页端不会显示检查更新入口

## AI模型管理为什么只有 DeepSeek

- 当前版本的 AI 模型管理只开放 DeepSeek 选项
- 先配置并启用默认模型，再到主设计器里的 [AI融合](../main_desiner/ai_fusion.md) 使用

## 蓝图节点为什么拖不上去

- 先确认当前蓝图页面是否已经加载完成
- 图层节点和全局变量节点通常只能拖拽一次
- 如果你正在找功能节点，可以先切到“功能节点”分类再搜索

## 页面变卡怎么办

- 压缩图片、视频、字体和 3D 模型等资源
- 不必要的资源尽量按项目拆分
- 如果你发布的是大页面，优先检查是否一次性渲染了太多组件
