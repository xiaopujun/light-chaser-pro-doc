# 常见问题

## 为什么我看不到用户管理或设置菜单？

首页的 **用户管理**和 **设置**菜单仅对系统管理员显示。普通账号可从左下角账号菜单打开账号设置。不要通过修改地址来代替申请权限；服务端也会校验访问权限。

## 保存成功，换浏览器却找不到本地快照？

**保存项目**将当前内容写入服务器；自动快照保存在当前浏览器的本地存储中，每 5 分钟记录一次，最多保留 10 条。换设备、换浏览器或清理站点数据后，原浏览器快照不一定可用。恢复入口是 **更多项目操作 → 本地自动存储恢复**。详见 [保存](/functions/main_desiner/save.md)。

## 点击预览没有打开页面？

预览先保存项目，再打开浏览器新标签页。先检查保存是否失败，再检查浏览器是否拦截新标签页。预览需要登录，分享给访问者应使用 **发布管理**中的发布地址，而不是编辑器地址或 `/preview`。

## 发布页无法访问？

检查发布记录是否存在、是否到期、是否设置访问密码。浏览器还必须能够访问当前站点和项目所依赖的外部数据、媒体资源。发布管理中的有效期和密码可在编辑发布记录时调整，详见 [发布管理](/functions/home/release_management.md)。

## 导入后图片、视频或字体没有显示？

确认 ZIP 包可正确解密，项目引用的资源文件与外部链接仍可用。涉及公共 API 或数据库的导出会要求加密口令；导入时需要相同口令。不要把浏览器本地快照当作可迁移的项目包。详见 [导入导出](/functions/main_desiner/export_import.md)。

## AI 为什么不能发送，或找不到想用的型号？

先在首页 **AI模型管理**中添加并启用模型配置，再到设计器 **AI驱动**分别选择“模型配置”和“模型型号”。管理页维护的是厂商接入参数；可用型号以 AI 面板加载的列表为准。当前支持多个提供商，不再只有 DeepSeek。没有可用模型、接入地址错误或服务端无法访问提供商时，任务无法正常运行。详见 [AI 模型管理](/functions/home/ai_model_management.md)。

## 开启“允许 SQL 脚本”后为什么仍不能执行非 SELECT？

当前数据库连接表单确实有此开关，但 Web SQL 执行接口仍要求语句以 `SELECT` 开头。不要把该开关视为已经支持写入、存储过程或任意 SQL 的保证。详见 [数据库管理](/functions/home/database.md)。

## Web 端如何检查更新？

系统管理员可在 **设置 → 关于**中检查 Web 更新。更新提示用于获知版本信息，服务器部署仍需由维护者完成；它不是桌面应用的自动下载安装流程。详见 [升级指南](/upgrade/upgrade.md)。

## 蓝图节点为什么拖不上去？

先确认蓝图已经加载。相同组件或同名全局变量的节点不能在同一蓝图中重复添加；先检查画布中是否已存在该节点。寻找内置逻辑时切到 **功能节点**分类。详见 [蓝图使用流程](/functions/blue_print/use_flow.md)。
