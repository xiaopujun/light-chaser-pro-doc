# 组件开发

Web 端提供内置组件和服务器组件扩展。自定义服务器组件可以用官方脚手架开发，再通过 Web 端“服务器组件”管理页上传；发布项目会按其组件依赖加载对应的远程组件。

`CLI 创建项目 → 实现组件与配置 → 本地预览并打包 → Web 端上传 → 设计器使用并发布`

- [脚手架开发组件](/develop/develop_pro.md)：创建项目、实现 Web 组件接口、开发预览、打包和上传。
- [配置面板与 JSON Schema UI](/develop/ui.md)：用 schema 生成配置表单，并把变更合并到组件配置。

脚手架里的 `light-chaser-interface` 是给组件编译使用的类型与抽象定义。Web 仓库中的 `lcp-web-interface` 也只提供接口定义；运行时实现由 Web 应用提供。请按当前 CLI 生成的模板和依赖包名开发。
