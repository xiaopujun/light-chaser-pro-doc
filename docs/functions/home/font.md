# 字体管理

字体管理用于上传项目可复用的字体文件，并在列表中预览字体效果。进入方式：左侧“资源管理”→“字体”。

## 支持的格式和操作

- 文件格式：`.ttf`、`.otf`、`.woff`、`.woff2`、`.eot`。
- 每次最多选择 10 个字体文件上传，可点击选择或拖拽到上传区。
- 搜索框可按字体名称筛选。
- 可修改字体名称，也可选择单个或多个字体删除。

## 上传字体

1. 点击“上传字体”。
2. 选择或拖入字体文件，确认待上传列表。
3. 点击“上传字体”等待完成，再在列表卡片中查看预览。

上传完成后，字体可在设计器的字体配置中引用。删除前请确认没有项目仍在使用该字体。
