# 数据源管理

Web 侧栏的“数据源管理”分组包含数据库管理和 API 管理两个页面。这里用于保存可在项目中复用的连接配置。

![Web 数据库连接新建表单](../../assets/web-2026-10/home-datasource.webp)

## 数据库管理

支持 MySQL、PostgresSQL、Oracle 和 SQLServer。保存数据库类型、连接地址和账号信息后，可在数据源卡片上测试连接；也可编辑、复制或删除连接。

表单还包含可选的“允许执行存储过程、函数和 SQL 脚本”开关，启用后数据源卡片会显示 SQL 脚本标记。在项目中通过数据库连接运行 SQL 时，目前仍需以 `SELECT` 开头；不要依赖这个开关执行写入语句或其他非查询语句。

详细字段和限制见[数据库管理](/functions/home/database.md)。

## API 管理

公共 API 配置包含名称、请求地址、请求方式、请求头和请求参数。编辑器中可以测试请求并查看响应；列表支持搜索、分页、复制和删除。

详细步骤见[API 管理](/functions/home/api.md)。
