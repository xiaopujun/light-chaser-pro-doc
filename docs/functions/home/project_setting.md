# 项目设置

## 总览

项目设置用于管理当前项目的专属内容。当前版本里，它主要用来配置项目级动态脚本。

## 怎么进入

1. 打开 [项目列表](project_list.md)
2. 在目标项目上点击 `设置`
3. 进入项目设置后切换到 `动态脚本`

## 当前可配置内容

- 动态脚本

## 使用说明

- 项目级动态脚本只对当前项目生效
- 适合给单个项目单独加工具库、效果库或业务脚本
- 如果你想让所有项目都能使用同一份脚本，请到 [资源管理](resource_management.md) 中的 [动态脚本](global_dynamic_script.md) 里配置

?> 项目级动态脚本和全局动态脚本的作用类似，只是生效范围不同。
