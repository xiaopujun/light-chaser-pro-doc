# 服务器组件

![服务器组件.png](服务器组件.png)

## 总览

服务器组件用于扩展主设计器中的可用组件。你可以把开发好的组件上传到这里，再在项目中直接使用。

一般流程是：

1. 使用开发脚手架完成组件开发
2. 打包生成产物
3. 在这里上传产物
4. 回到主设计器使用新组件

?> 如果你还没有开始开发组件，可以先看 [脚手架开发组件](/develop/develop_pro)

## 上传服务器组件

假设你已经开发好了一个服务器组件并完成打包，可以直接上传到这里。

目前支持上传 `.js` 和 `.mjs` 文件。

![上传服务器组件.png](上传服务器组件.png)

## 替换组件

上传后你还可以替换已有组件，更新组件文件但保留原有使用位置。

![替换组件.png](替换组件.png)

## 使用服务器组件

上传完成后，组件会出现在主设计器组件列表中，可像普通组件一样拖拽使用。

!> 删除服务器组件前，请先确认没有项目正在使用它，否则相关页面可能无法正常渲染。
