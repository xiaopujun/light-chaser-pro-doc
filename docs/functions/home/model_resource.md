# 3D模型资源管理

## 总览

3D 模型资源管理用于上传和维护模型素材，方便在项目中重复使用。

## 支持的格式

- `.glb`
- `.gltf`
- `.fbx`
- `.obj`
- `.zip`

## 常用操作

- 上传模型
- 重命名模型
- 复制模型链接
- 删除模型

## 上传和预览

- 支持直接拖拽或选择文件上传
- 支持一次选择多个模型文件
- 桌面端单个模型建议控制在 500MB 以内
- 卡片会显示文件类型标签，方便区分格式

## 使用说明

- 右上角的菜单可以重命名、复制链接或删除
- 上传后可在项目中直接引用
- 如果你使用的是压缩包模型，建议保持内部文件结构完整
- 删除前请确认没有项目正在使用该模型
