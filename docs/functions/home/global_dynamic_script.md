# 全局动态脚本

全局动态脚本是资源管理中的脚本工作区，适合保存多个项目都要加载的公共脚本。进入方式：左侧“资源管理”→“动态脚本”。

## 支持的脚本

- **在线脚本**：填写脚本或 CDN 地址。
- **本地脚本**：上传 `.js` 文件。

列表支持搜索、分页、修改名称和删除，也可一次选择多条记录批量删除。

## 创建脚本

1. 点击“创建”。
2. 选择在线脚本或本地脚本。
3. 填写名称，并补充脚本地址或选择 `.js` 文件。
4. 保存后，在需要的项目中引用该脚本。

全局脚本适用于多个项目共用的工具库或公共逻辑。如果只对一个项目生效，请改用[项目级动态脚本](/functions/home/project_dynamic_script.md)。删除脚本前请先检查项目依赖。
