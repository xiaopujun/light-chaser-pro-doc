# 画布

中央画布用于放置和编辑组件。画布设置从主设计器工具栏打开，修改画布宽高、适配方式和栅格设置后点击 **确定**生效。

![Web 端画布设置](../../assets/web-2026-10/designer-canvas.png)

## 画布尺寸和屏幕适配

画布尺寸以像素设置。屏幕适配包含以下方式：

- **自适应**：按显示区域缩放并保持原始比例，比例不同时会留白。
- **撑满宽度**：以显示区域宽度为基准缩放；超出高度时可纵向滚动。
- **撑满高度**：以显示区域高度为基准缩放；超出宽度时可横向滚动。
- **撑满全屏**：宽高方向分别适配显示区域，画布比例可能改变。
- **无自适应**：按画布原始宽高显示，不进行屏幕缩放。

## 框选与栅格化

画布设置提供 **完整框选**开关。开启后，框选区域必须完整包含组件才会选中；关闭时，组件与选区相交即可选中。

开启 **栅格化**后，可设置拖拽步长和缩放步长。移动或调整组件尺寸时，位置和尺寸会按相应步长对齐；关闭后不按栅格步长吸附。底部的磁铁按钮是另一项排版吸附开关，控制拖拽/缩放时对相邻组件和画布边缘的贴齐效果，见[自动吸附](/functions/main_desiner/auto_snapping.md)。

## 移动画布与缩放

工具栏提供选择工具和抓手工具；按住空格可临时切换抓手。默认也可按住鼠标右键拖动画布，按住 `Alt`（macOS 为 `Option`）并滚动鼠标滚轮缩放画布。当前缩放比例显示在工作区底部。
