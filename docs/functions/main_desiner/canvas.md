# 画布

## 总览

![画布.png](画布.png)

主设计器的中间位置即为画布，画布是最终设计效果要呈现的区域。在主设计器中，你可以往画布里放入组件，并设置你想要的效果。预览或发布时，画布中的组件会根据你设置的属性进行渲染。

## 画布设置

当你新建完毕一个项目后，会根据你设定的画布尺寸来渲染画布。若后续你需要修改画布尺寸，可以在顶部的画布设置中进行调整。除此之外，你还可以设置一些画布渲染的具体细节。

![画布设置.png](画布设置.png)

### 画布尺寸

对于画布尺寸，你可以根据最终要使用的显示器尺寸或者笔记本尺寸进行设置。设置完成后点击确定，新的画布效果会立即生效。

### 屏幕适配

屏幕适配是为了让最终预览时的效果尽可能适配不同屏幕。当前包含五个选项：

![屏幕适配.png](屏幕适配.png)

#### 自适应

画布会根据显示器的实际比例进行计算，保持画布始终居中渲染。此种情况下，如果画布比例与显示器比例不一致，会出现留白，因此建议画布比例尽量和目标显示器一致。

![自适应.png](自适应.png)

#### 撑满宽度

此选项下，即使画布比例与显示器比例不一致，也会将画布宽度强行撑满显示器宽度。若画布高度小于显示器高度，会留白；若画布高度更高，则会出现纵向滚动。

![撑满宽度.png](撑满宽度.png)

#### 撑满高度

撑满高度与撑满宽度相对。此选项下，即使画布比例与显示器比例不一致，也会将画布高度强行撑满显示器高度。若画布宽度小于显示器宽度，会留白；若画布更宽，则会出现横向滚动。

![撑满高度.png](撑满高度.png)

#### 撑满全屏

此项与前面三项差异较大。不管画布比例与显示器比例是否一致，都会强行将画布撑满显示器，因此不会出现留白问题。但如果画布尺寸比例与显示器尺寸不一致，组件可能会出现比例失衡。

![撑满全屏.png](撑满全屏.png)

#### 无自适应

画布按原始尺寸显示，不主动做缩放适配。适合调试特殊布局，或者你希望自己控制容器显示方式的场景。

### 栅格化

![栅格化.png](栅格化.png)

开启栅格化会影响编辑模式下组件的拖拽和缩放效果。当你把拖拽步长设置为 20 时，在画布中拖拽组件时，每次移动的最小距离就是 20 像素。缩放步长则会影响调整组件尺寸时的最小单位像素。

栅格化适合在做整体布局时快速对齐和统一间距。

## 操作画布

画布的操作过程与Photoshop类似：

- 拖拽画布：你可以通过按住鼠标右键不松手，然后移动鼠标进行画布的拖拽。
- 缩放画布：你可以按住alt + 鼠标滑轮进行画布的缩放。缩放是以鼠标指针为中心进行缩放的。可以最大程度满足你缩放哪里查看哪里的需求。

不管画布拖拽还是缩放，画布渲染都是实时进行的，标尺的刻度也是实时更新的。

你可以在画布的右下角观察到当前画布的缩放比例
