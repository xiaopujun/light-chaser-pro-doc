# 全局变量

全局变量主要用于动态填充组件数据源配置，也可以作为数据源之一驱动组件数据变更。

## 使用流程

1. 新建全局变量并设置 key 和 value
2. 需要自动触发时，给变量配置数据来源
3. 在组件的数据源或占位符中引用这个变量
4. 需要联动时，把变量绑定到目标组件或蓝图节点
5. 预览或发布时，变量变化会驱动对应内容更新

## 作为占位符

![全局变量占位符.png](全局变量占位符.png)

目前支持在如下配置中使用全局变量作为占位符：

### 数据源配置 - 接口（API）

1. 接口地址
2. 请求头
3. 请求参数
4. 过滤器

### 数据源配置 - 公共API

1. 过滤器

### 数据源配置 - 数据库

1. SQL语句
2. 过滤器

### 数据源配置 - WebSocket

1. WS地址
2. 过滤器

### 数据源配置 - MQTT

1. 地址
2. 主题
3. 过滤器

## 作为数据源

![全局变量作为数据源.png](全局变量作为数据源.png)

作为数据源时，全局变量可以直接驱动绑定组件刷新，适合做表单联动、数据显示切换和接口参数复用。

## 作为蓝图节点

![全局变量作为蓝图节点.png](全局变量作为蓝图节点.png)

作为蓝图节点时，可以把变量变化接到事件流里，继续驱动其他组件或页面动作。
