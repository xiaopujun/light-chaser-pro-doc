# 全局变量

全局变量保存在当前项目中，可供组件数据源、请求参数和蓝图复用。左侧栏打开“全局变量”后，可创建变量；变量列表显示名称、更新方式和绑定组件数量，并提供编辑、复制、删除操作。

## 创建变量

1. 在全局变量面板点击 **新建全局变量**。
2. 设置变量名和数据来源。可用来源包括静态值、API、公共 API、数据库、WebSocket 和 MQTT。
3. 设置静态默认值；数据源尚未返回首次结果时，会使用该值。
4. 如需变量值变化时主动刷新绑定组件，开启 **主动渲染**。

## 作为占位符

在支持的配置字段中使用 `#{key}` 引用变量，其中 `key` 是变量名（可使用英文字母、数字、`_` 和 `-`）。支持位置如下：

| 数据源 | 支持的字段 |
| --- | --- |
| API | 地址、请求头、请求参数、过滤器 |
| 公共 API | 过滤器 |
| 数据库 | SQL 语句、过滤器 |
| WebSocket | 地址、过滤器 |
| MQTT | 地址、主题、过滤器 |

例：变量名为 `deviceId` 时，可在 API 参数值中填写 `#{deviceId}`。

## 作为组件数据源

在组件的“数据”配置中选择全局变量并选取变量，即可把变量当前值直接提供给组件。组件会与该变量建立绑定；开启主动渲染后，变量更新会触发绑定组件刷新。

## 作为蓝图节点

在蓝图左侧的全局变量节点中添加变量后，可从“数据变更时”输出连接后续节点；“更新数据”输入可用来更新变量值。
