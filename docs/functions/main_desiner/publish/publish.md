# 发布

发布会为当前主项目创建可访问的展示页面。它适合分享或交付；预览则用于登录后的项目检查。发布配置窗口可从主设计器顶部的 **发布**按钮打开；即使当前正在编辑子项目，发布的也仍是主项目。

![Web 端发布配置](../../../assets/web-2026-10/designer-publish.png)

## 发布项目

1. 打开发布配置，选择发布类型。
2. 如需保护访问权限，开启“访问加密”并设置密码。
3. 可设置有效期，单位为天；不填写时表示永久有效。
4. 点击 **发布项目**。发布成功后，窗口会提供 **查看发布**入口。

### 发布类型

- **覆盖发布**：更新已有发布内容；如果还没有发布，则创建首个发布。适合沿用同一个访问链接更新页面。
- **增量发布**：创建新的发布链接，适合保留现有版本并分享另一份发布。

开启访问加密后，访问者需要输入密码才能查看发布页面。请通过安全渠道把密码提供给访问者。

## 查看和管理发布

点击 **查看发布**会在浏览器新标签页打开发布页面。也可以从首页的[发布管理](/functions/home/release_management.md)查看发布记录和访问链接。发布页面按项目画布尺寸和屏幕适配方式渲染；发布前应检查组件、数据源和外部资源。
