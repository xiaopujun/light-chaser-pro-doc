# Web 发布预览

Web 端通过“发布管理”展示已发布的项目。访客打开发布链接后会进入只读展示页面；页面渲染发布时保存的画布内容，不提供设计器编辑面板。

## 打开发布项目

1. 在主设计器中完成项目并保存。
2. 在首页打开“发布管理”，创建或找到对应的发布项目。
3. 使用发布管理中的预览入口打开项目。
4. 如果发布项目启用了访问密码，访客需要输入密码后才能加载内容。

发布页链接形式为 `/release/<发布 ID>`。发布内容会按项目配置加载资源、字体、动态脚本和服务器组件；这些资源仍需能够从浏览器访问。

## 与设计器预览的区别

- `/release/:id` 展示已发布项目，可通过发布密码限制访问。
- `/preview` 是登录后的项目预览入口，需要用户认证。
- 当前 Web 路由没有独立的“演示项目列表”、本地 zip 导入或演示项目删除流程；这页说明的是 Web 发布预览。

如果发布页缺少图片、字体或组件，先检查发布项目包含的资源和浏览器能访问的资源地址。
