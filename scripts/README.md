# 文档截图

`docs/assets/web-2026-10/originals/` 保留 25 张未标注的 **1920 × 1080 WebP** 截图。正文引用上一层目录的 WebP 标注图；其中主题、封面、快捷键、蓝图页面和变量使用同一原图的专用标注版本，共 30 张标注图。

原图由浏览器区域截图接口采集，之后转换为 WebP。采集时逐张检查实际像素尺寸、页面完整性和文字清晰度；不放大、拉伸或补黑边来满足尺寸要求。弹窗外的背景虚化属于应用自身的遮罩效果。

四个生成脚本仅叠加标注，从 `originals/*.webp` 读取截图，并以无损 WebP 输出；遇到非 1920 × 1080 原图会停止，不裁切或缩放底图。需要支持 WebP 的 Pillow、Python 3 和脚本中指定的 macOS 系统字体。在仓库根目录运行：

```bash
python3 scripts/annotate_home_1080.py
python3 scripts/annotate_designer_1080.py
python3 scripts/annotate_advanced_1080.py
python3 scripts/annotate_context_1080.py
```

脚本可用第一个参数指定其他原图目录。界面布局变化后，应重新采集并按新画面调整标注坐标。

标注要同时帮助定位操作与理解规则：指出控件后，应说明选择条件、操作结果、必填项或容易误用的边界，避免只改写控件标题。规则以当前实现核验，不为凑“禁止事项”添加产品没有的限制。每张只保留当前任务的关键规则；不同任务不要强行复用同一张泛总览标注。

`annotation_rules.py` 提供统一的说明框样式、文字换行和范围校验。规则的源码依据写在各生成脚本的注释中。发布图保留已确认的版本，其他图使用相同的定位、正文说明与边界提示层次。生成后还需逐张检查图片，确认箭头落点、控件可见性和说明内容。
